# filebox/ — بخشِ «فایل‌ها» (سایدبار)

عمداً ساده (خواستِ کاربر): آپلود، **لینکِ اشتراکی**، تغییرِ نام، کپیِ لینک، حذف — همین.
- **مدل `SharedFile`** (tenant: `objects`/`all_objects`): `name` (یکتا در سازمان)، `file`، `size`، **`token`** (ثابت؛ لینک =
  `/f/<token>/`)، `uploaded_by`. `kind` (property) نوعِ آیکن را از پسوند می‌دهد (`image`، `file-pdf`، …).
- **لینکِ عمومی `filebox.views.public`** بدونِ ورود سرو می‌کند (`all_objects`؛ تصویر/PDF/ویدیو inline، بقیه دانلود).
  چون توکن ثابت است، **جایگزین‌کردنِ محتوا یا تغییرِ نام لینکِ قبلی را خراب نمی‌کند.**
- **هم‌نام:** آپلود/تغییرِ نامِ هم‌نام → **409 `{conflict, name}`**؛ UI می‌پرسد «جایگزین شود؟» و با `replace=1`/`replace:true`
  دوباره می‌فرستد. آپلود = محتوای همان رکورد عوض می‌شود (فایلِ قدیمی را django-cleanup پاک می‌کند)؛ تغییرِ نام = رکوردِ
  هم‌نامِ قبلی حذف می‌شود. پسوند در تغییرِ نام اگر حذف شده باشد خودکار برمی‌گردد.
- **گیت:** پرمیشنِ `shared_files` (گروهِ «پروژه‌ها»؛ نقشِ «سرپرست» پیش‌فرض دارد؛ نقش‌های سفارشیِ قدیمی را دستی تیک بزن) —
  هم سرور (`require_perm`) هم لینکِ سایدبار. سقفِ حجم ۲۰MB (nginx ۲۵M).
- UI: `templates/filebox/index.html` (یک رندرکنندهٔ JS از `json_script`؛ `send()`ِ خودش به‌جای `App.fetchJSON` تا 409 توست
  نشود) + بلوکِ «بخشِ فایل‌ها» ته `style.css` (`.fb-*`).
