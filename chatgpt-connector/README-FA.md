# ChatGPT-WP — اتصالِ ChatGPT Desktop به سایت‌های وردپرسی

یک برنامهٔ کوچکِ ویندوزی که ChatGPT Desktop (حالتِ **Work**) را مستقیم به سایت‌هایت وصل می‌کند تا
مقاله و متنِ دسته‌بندیِ محصول را **کامل** بنویسد: تحقیقِ رقبا، گوگل، لینکِ داخلی، عکس و سئو — و
همه‌چیز را به‌صورتِ **پیش‌نویس** در وردپرس ذخیره کند. **همهٔ مدیریت از پنلِ خودِ برنامه است.**

- اتصال به ChatGPT: MCP (پلاگینِ محلی). اتصال به سایت‌ها: **REST API وردپرس** با Application Password.
  روی سایت‌ها هیچ افزونهٔ اضافه‌ای لازم نیست.
- همه‌چیز روی همین کامپیوتر اجرا می‌شود (سایت‌های ایرانی از سرورهای OpenAI در دسترس نیستند، ولی از کامپیوترِ تو هستند).

## دانلود
آخرین نسخه همیشه در مخزنِ گیت‌هاب است: `chatgpt-connector/release/ChatGPT-WP.zip` (روی فایل ← Download).

## نصب (یک بار)
1. **Node.js** (نسخهٔ LTS) از https://nodejs.org (اگر داری، لازم نیست). Chrome یا Edge هم باشد.
2. zip را **Extract** کن و روی **`INSTALL.cmd`** دوبار کلیک کن.
3. پنل در مرورگر باز می‌شود و میان‌برِ «ChatGPT-WP Panel» روی دسکتاپ ساخته می‌شود (دفعه‌های بعد از همین باز کن).
4. ChatGPT Desktop را کامل ببند و باز کن ← Plugins ← **Local Private Plugins** ← «SEO WordPress Connector» را فعال کن.

## همگام‌سازی بینِ چند کامپیوتر (از طریقِ پنلِ سئو منیجر)
1. در پنلِ سئو منیجر: تنظیمات ← **توکن‌های API** ← توکنِ جدید (هرکس برای خودش).
2. در برنامه: ⚙ تنظیمات ← «همگام‌سازی با پنل» ← آدرسِ پنل + توکن ← «ذخیره و همگام‌سازی».
3. از آن به بعد خودکار است: موقعِ باز شدن، هر چند دقیقه (پیش‌فرض ۵)، و چند ثانیه بعد از هر تغییر. دکمهٔ «همگام‌سازیِ الان» هم هست.
- سایت‌ها، پرامپت‌ها، رقبا، فایل‌ها و رمزها (روی پنل رمزنگاری‌شده) همگام می‌شوند. لاگینِ مرورگر، مسیرِ مرورگر و پراکسی مالِ هر کامپیوتر می‌مانند.
- اگر دو نفر هم‌زمان یک **سایت** را عوض کنند، آخرین تغییر می‌ماند؛ تغییر روی سایت‌های مختلف با هم ادغام می‌شود.
- اگر پنل در دسترس نبود، برنامه با دادهٔ همین کامپیوتر کار می‌کند و دفعهٔ بعد همگام می‌شود (وضعیت در چیپِ «🔄» بالای پنل).
- وضعیت در پنلِ سئو منیجر: تنظیمات ← «همگام‌سازی ChatGPT-WP».

## به‌روزرسانی
در پنل **«⬆ به‌روزرسانی با zip»** و انتخابِ zipِ جدید (Extract لازم نیست). سایت‌ها، پرامپت‌ها، فایل‌ها و
لاگین‌های مرورگر دست نمی‌خورند. بعدش ChatGPT Desktop را یک بار ببند و باز کن.

## پنل
- **＋ سایتِ جدید:** نامِ کوتاه (همان که در ChatGPT می‌گویی)، آدرس، نام کاربری، **رمزِ برنامه**، افزونهٔ سئو.
  پرامپت‌های اولیه: نمونه‌های آماده، خالی، یا کپی از یک سایتِ دیگر.
  ساختِ رمزِ برنامه: پیشخوان ← کاربران ← شناسنامه ← Application Passwords ← نام ← افزودن.
- هر سایت چهار تب دارد:
  - **اتصال:** ویرایش + «تستِ اتصال» (کاربر، نقش، Rank Math/ووکامرس، تعدادِ مطالب).
  - **پرامپت‌ها (مخصوصِ همین سایت):** **عمومی** = همیشه رعایت می‌شود (هر تعداد). **اختصاصی** = برای یک نوع کار
    (مثلاً «مقاله جدید»، «متن دسته‌بندی محصول») با تیکِ مراحلِ لازم: بررسی رقبا (+ تعداد)، نتایج گوگل، گوگل ساجست،
    لینک داخلی، عکس. **تیک نخورده = انجام نمی‌شود** (مگر در متن یا چت بخواهی).
  - **فایل‌ها:** بکش و رها کن؛ «آپلود برای» = کلِ سایت یا یک پرامپت؛ کاربرد = تصویر شاخص پیش‌فرض / تصویر شاخص /
    داخل متن / لوگو / مرجع / سایر + توضیح. پوشه‌بندی خودکار است (`files\<سایت>\` و `files\<سایت>\<پرامپت>\`).
    «تصویر شاخص پیش‌فرض» = اگر مقالهٔ جدید عکسِ شاخص نداشت همین گذاشته می‌شود. «مرجع» = ChatGPT قبل از نوشتن می‌خواند.
  - **رقبا:** رقیب (به ChatGPT معرفی می‌شود) یا «نادیده بگیر» (مثلاً دیجی‌کالا/ترب در نتایج رقیب حساب نشوند).
- **تنظیمات:** زبان/کشورِ گوگل، Chrome یا Edge، نمایشِ مرورگر، پراکسی، خطای SSL، سقفِ طولِ جواب + تستِ گوگل و مرورگرِ ابزار.

تغییراتِ پنل بلافاصله در ChatGPT اثر دارد.

## نمونهٔ دستور در ChatGPT (Work)
- «برای steeltak با پرامپتِ ‹مقاله جدید› دربارهٔ ‹ورق استیل ۳۰۴› مقاله بنویس و پیش‌نویس کن.»
- «متنِ دستهٔ محصولِ ‹لوله استیل› در steeltak را با پرامپتِ ‹متن دسته‌بندی محصول› بنویس؛ قبل از ذخیره نشانم بده.»
- «بعد از ذخیره، مطالبِ قدیمی که می‌توانند به این مقاله لینک بدهند را پیدا کن و پیشنهاد بده.»

## پوشهٔ کاری `%USERPROFILE%\ChatGPT-WP`
`config.json` (همهٔ تنظیمات) · `files\` (فایل‌های سایت‌ها) · `images\` (عکس‌هایی که خودت ذخیره می‌کنی؛ در چت فقط نامِ فایل را بگو) ·
`backups\` (متنِ قبلیِ هر مطلب/دسته‌ای که ویرایش شد) · `logs\app.log` (برای عیب‌یابی؛ از تنظیمات ← «فایلِ لاگ»).

## مشکلات رایج
- **401** در تستِ اتصال: رمزِ برنامه/نام کاربری اشتباه است؛ یا هاست هدرِ Authorization را حذف می‌کند (به پشتیبانیِ هاست بگو).
- **گوگل کپچا داد:** تنظیمات ← «مرورگرِ ابزار» و یک بار کپچا را حل کن.
- **پلاگین در ChatGPT دیده نمی‌شود:** ChatGPT را از System Tray هم ببند؛ در صفحهٔ «وضعیت» پلاگین باید ✓ باشد.
- **عنوان/توضیحِ سئو ثبت نشد:** گزارشِ ChatGPT مقادیر را می‌دهد تا دستی وارد کنی.

> امنیت به خواستِ کاربر حداقلی است: رمزها در `config.json` به‌صورتِ ساده‌اند. این فایل را به اشتراک نگذار.
> برای قطعِ دسترسی، Application Password را از پیشخوانِ وردپرس حذف کن.
