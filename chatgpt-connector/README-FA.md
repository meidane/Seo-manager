# ChatGPT-WP — اتصالِ ChatGPT Desktop به سایت‌های وردپرسی

یک برنامهٔ کوچکِ ویندوزی که ChatGPT Desktop (حالتِ **Work**) را مستقیم به سایت‌هایت وصل می‌کند تا
مقاله و متنِ دسته‌بندیِ محصول را **کامل** بنویسد: تحقیقِ رقبا، گوگل، لینکِ داخلی، عکس و سئو — و
همه‌چیز را به‌صورتِ **پیش‌نویس** در وردپرس ذخیره کند. تنظیمات فقط در یک **فایلِ اکسل** است.

- اتصال به ChatGPT: MCP (پلاگینِ محلی). اتصال به سایت‌ها: **REST API وردپرس** با Application Password.
  روی سایت‌ها هیچ افزونهٔ اضافه‌ای لازم نیست.
- همه‌چیز روی همین کامپیوتر اجرا می‌شود (سایت‌های ایرانی از سرورهای OpenAI در دسترس نیستند، ولی از کامپیوترِ تو هستند).

## نصب (یک بار)
1. **Node.js** (نسخهٔ LTS) را از https://nodejs.org نصب کن (اگر از قبل داری، لازم نیست).
2. Google Chrome یا Microsoft Edge (برای تحقیقِ گوگل/رقبا؛ Edge در ویندوز هست).
3. zip را **Extract** کن (کلیکِ راست ← Extract All) و در پوشهٔ بازشده روی **`INSTALL.cmd`** دوبار کلیک کن.
4. پنل در مرورگر باز می‌شود و یک میان‌بر «ChatGPT-WP Panel» روی دسکتاپ ساخته می‌شود.
5. در پنل «📊 باز کردنِ اکسل» → برگهٔ «سایت‌ها» را پر کن → ذخیره → «↻ دوباره خواندن» → «تستِ اتصال».
6. ChatGPT Desktop را کامل ببند و باز کن ← Plugins ← **Local Private Plugins** ← «SEO WordPress Connector» را فعال کن.

## به‌روزرسانی
در پنل **«⬆ به‌روزرسانی با فایل zip»** را بزن و zipِ جدید را انتخاب کن (Extract لازم نیست).
یا zipِ جدید را Extract کن و دوباره `INSTALL.cmd`. اکسل، عکس‌ها، فایل‌ها و لاگین‌های مرورگر **دست نمی‌خورند**.
بعد از به‌روزرسانی، ChatGPT Desktop را یک بار ببند و باز کن.

## پوشهٔ کاری: `%USERPROFILE%\ChatGPT-WP`
| چیز | کار |
|---|---|
| `sites.xlsx` | همهٔ تنظیمات (برگه‌ها پایین) |
| `images\` | عکس‌های مقاله؛ در چت فقط نامِ فایل را بگو |
| `files\<نام سایت>\` | فایل‌های همهٔ کارهای آن سایت (خودکار ساخته می‌شود) |
| `files\<نام سایت>\<عنوان پرامپت>\` | فایل‌های فقط همان پرامپت |
| `files\همه\` | فایل‌های همهٔ سایت‌ها |
| `backups\` | متنِ قبلیِ هر مطلب/دسته‌ای که ویرایش شد (خودکار) |

**کاربردِ فایل از نامش:** `پیشفرض.jpg` = تصویرِ شاخصِ پیش‌فرضِ مقاله‌های جدید · «شاخص» · «لوگو» ·
«مرجع»/«نمونه» (متن/راهنما که قبل از نوشتن خوانده می‌شود) · بقیهٔ عکس‌ها = داخلِ متن.
توضیح برای هر فایل: یک فایلِ txt هم‌نام کنارش (`banner.jpg` + `banner.txt`). همین‌ها را می‌توانی در برگهٔ «فایل‌ها»ی اکسل هم بنویسی.

## برگه‌های اکسل
- **سایت‌ها:** نام کوتاه · آدرس · نام کاربری · رمز برنامه (Application Password) · افزونهٔ سئو (rankmath/yoast) · فعال.
  ساختِ رمز برنامه: پیشخوان ← کاربران ← شناسنامه ← Application Passwords ← نام ← افزودن.
- **پرامپت‌ها:** «نوع پرامپت» = **عمومی** (همیشه رعایت می‌شود؛ هر تعداد) یا **اختصاصی** (برای یک کار، مثلاً «مقاله جدید»).
  ستون‌های **بررسی رقبا / تعداد رقبا / نتایج گوگل / گوگل ساجست / لینک داخلی / عکس**: فقط «بله»ها انجام
  می‌شوند؛ خالی = لازم نیست (مگر در متنِ پرامپت یا چت بخواهی). ستونِ «سایت» = نام کوتاه یا «همه».
- **فایل‌ها:** سایت · عنوان پرامپت (خالی = همه) · مسیر · کاربرد · توضیح.
- **رقبا:** دامنهٔ رقبای اصلی (نوع = رقیب) یا سایت‌هایی که رقیب حساب نشوند (نوع = نادیده).
- **تنظیمات:** زبان/کشورِ گوگل، Chrome یا Edge، نمایشِ مرورگر، پراکسیِ مرورگر، خطای SSL، سقفِ طولِ خروجی.

تغییرِ اکسل بلافاصله اثر می‌کند (ری‌استارت لازم نیست).

## نمونهٔ دستور در ChatGPT (Work)
- «برای steeltak با پرامپتِ ‹مقاله جدید› دربارهٔ ‹ورق استیل ۳۰۴› مقاله بنویس و پیش‌نویس کن.»
- «متنِ دستهٔ محصولِ ‹لوله استیل› در steeltak را با پرامپتِ ‹متن دسته‌بندی محصول› بنویس؛ قبل از ذخیره نشانم بده.»
- «بعد از ذخیره، مطالبِ قدیمی که می‌توانند به این مقاله لینک بدهند را پیدا کن و پیشنهاد بده.»

## ابزارها (برای اطلاع)
`sites` (بریف از اکسل) · `wp_check` · `wp_find` · `wp_get` · `wp_save_post` (Markdown/HTML، آپلودِ خودکارِ عکس،
پیش‌نویس، سئو) · `wp_save_term` (متنِ دسته) · `wp_upload_media` · `wp_internal_links` · `wp_link_opportunities` ·
`wp_add_link` · `wp_api` (هر درخواستِ REST) · `google_suggest` · `serp` · `page_outline` · `competitor_research` ·
`browser_run` (اسکریپتِ آزادِ Playwright) · `http_fetch` · `files_list` · `file_read`.

## مشکلات رایج
- **401** در تستِ اتصال: رمز برنامه/نام کاربری اشتباه است؛ یا هاست هدرِ Authorization را حذف می‌کند
  (به پشتیبانیِ هاست بگو `CGIPassAuth On` یا قاعدهٔ `.htaccess` برای Authorization را اضافه کند).
- **گوگل کپچا داد:** در پنل «🌐 باز کردنِ مرورگرِ ابزار» و یک بار کپچا را حل کن.
- **پلاگین در ChatGPT دیده نمی‌شود:** ChatGPT را از System Tray هم ببند؛ در پنل وضعیتِ «پلاگینِ ChatGPT» باید ✓ باشد.
- **عنوان/توضیحِ سئو ثبت نشد:** گزارشِ ChatGPT مقادیر را می‌دهد تا دستی وارد کنی (بسته به نسخهٔ Rank Math).
- لاگِ برنامه در پنجرهٔ پنل و در ChatGPT (بخشِ MCP) دیده می‌شود.

> امنیت به خواستِ کاربر حداقلی است: رمزها در اکسل به‌صورتِ متنِ ساده‌اند و ابزارِ `browser_run`/`wp_api` محدودیت ندارد.
> اکسل را جایی به اشتراک نگذار. برای قطعِ دسترسی، Application Password را از پیشخوانِ وردپرس حذف کن.
