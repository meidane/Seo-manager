# personal/ — فضای شخصیِ خصوصی (فقط سوپریوزر)

داشبوردِ کاملاً خصوصیِ کاربرِ `admin`: اینباکسِ هفتگی، تسکِ روزانه، هبیت ترکر، اهداف،
ثانیه‌شمارِ عمر. عمداً **tenant-scoped نیست** — هر رکورد فقط به `user` تعلق دارد.

## امنیت (مهم)
- **گیت = `access.py: admin_only`** (دکوریتور، روی ویو با `method_decorator` و روی هر API).
  اگر سوپریوزر نبود **۴۰۴** می‌دهد (نه ۴۰۳ — وجودِ صفحه هم لو نرود).
- علاوه بر گیت، **همه‌ی کوئری‌ها به `user=request.user` اسکوپ‌اند** (حتی سوپریوزرِ دیگری
  دادهٔ کسی را نبیند): `get_object_or_404(Model, pk=pk, user=request.user)`.
- لینکِ سایدبار هم `{% if request.user.is_superuser %}` است.
- **فعلاً هیچ اپشنی برای بقیه نیست** (کسی نمی‌تواند فضای شخصیِ خودش بسازد) — طبقِ درخواست.

## مدل‌ها (`models.py`)
- `PersonalTask` — هم اینباکس (به تفکیکِ `week_start` = شنبه‌ی هفته) هم تسکِ روزانه (وقتی
  `planned_date` بگیرد). `playing` = فوکوسِ فعلی (فقط یکی هم‌زمان، در API اجرا می‌شود)؛
  `order` = ترتیبِ درگِ باکسِ روزانه.
- `Habit` + `HabitLog` — عادت با `weekdays` (شمسی شنبه=۰..جمعه=۶) و `polarity` (good/bad).
  لاگ = رعایتِ یک روز (unique(habit,date)). درصد در ویو حساب می‌شود (روزهای فعالِ گذشته).
- `Goal` — عنوان/توضیح/شروع/پایان؛ تایم‌لاینِ «چند روز گذشته» در ویو.
- **هفته = شنبه تا جمعه**: `models.week_saturday(d)` منبعِ واحد (با `core.jalali.g2j`).

## ویو/تمپلیت/JS
- `views.PersonalDashboardView` فقط رندرِ اولیه (SSR کاملِ باکس‌ها). تعامل با `api.py` (JSON).
- `templates/personal/index.html` + `static/js/personal.js`. ثانیه‌شمارِ عمر کاملاً فرانت است
  (birth/death از `data-*` — هارد‌کد در ویو: الان ۲۸ ساله، تا ۷۵).
- عملیاتِ سبک (تیک/پلی/حذف/درگ/تیکِ هبیت) درجا؛ عملیاتِ ساختاری (ویرایش/برنامه‌ریزی/
  افزودنِ عادت‌وهدف) `location.reload()` — عمداً ساده، کم‌کد.
- استایل: بلوکِ «فضای شخصی» ته `static/css/style.css` (فقط متغیرِ رنگ، طبقِ قانونِ ۲).
